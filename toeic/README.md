# 🏆 TOEIC 900+ 단어 마스터

토익 900점 이상을 목표로 하는 영단어 학습 웹사이트입니다. 서버나 빌드 과정 없이 `index.html`을 브라우저에서 열면 바로 동작합니다.

## 실행

```bash
cd toeic
python3 -m http.server 8000
# http://localhost:8000 접속 (또는 index.html을 더블클릭)
```

GitHub Pages 등 정적 호스팅에 폴더째 올려도 됩니다.

## 구성

- **단어 1,467개** · 12개 주제별 카테고리 (인사·채용, 사무·회의, 마케팅·영업, 재무·회계, 계약·법률, 생산·물류, 여행·숙박, 부동산·시설, 고객 서비스·식당, 행사·미디어·기술·환경, 900+ 핵심 고급 어휘, 혼동 어휘·연어·Part 5 빈출)
- 각 단어: 품사 · 뜻 · 동의어 · 토익 스타일 예문 · 난이도(기초 700 / 중급 800 / 고급 900+)
- **30일 커리큘럼**: 하루 50단어, 기초 → 고급 순 자동 배정
- **플래시카드 + 간격 반복(SRS)**: 아는/모르는 응답에 따라 1·3·7·14·30·60일 간격으로 복습 예약, 틀린 카드는 세션 안에서 즉시 재출제
- **퀴즈 5종 + 혼합 모드**: 영→한, 한→영, 동의어(Part 7 대비), 빈칸 채우기(Part 5 대비), 스펠링 타이핑. 범위(전체·레벨·카테고리·Day·취약 단어)와 문항 수 선택 가능
- **단어장**: 검색·카테고리·레벨·학습 상태 필터, 즐겨찾기, 발음 듣기(브라우저 TTS)
- **통계**: 900점 준비도 지표, 학습 단계 분포, 6주 학습 히트맵, 복습 예정표, 퀴즈 기록, JSON 백업·복원
- 키보드 단축키: 플래시카드 `Space` 뒤집기 · `1` 몰라요 · `2` 알아요, 퀴즈 `1~4` 선택 · `Enter` 다음
- 다크 모드, 모바일 대응

## 파일 구조

```
toeic/
  index.html      # 진입점
  style.css       # 스타일 (라이트/다크 테마)
  app.js          # 라우팅, SRS, 플래시카드, 퀴즈, 단어장, 통계
  data/words_*.js # 카테고리별 단어 데이터
```

### 단어 추가·수정

`data/words_N.js` 배열에 한 줄을 추가하면 됩니다.

```js
["단어", "품사", "뜻", "동의어", "예문", 레벨(1|2|3)],
```
