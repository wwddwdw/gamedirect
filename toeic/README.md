# TOEIC · SQLD · ADsP · 컴활 2급 마스터

토익 900점 어휘와 SQLD, ADsP, 컴퓨터활용능력 2급 핵심 용어를 간격 반복 플래시카드와 퀴즈로 학습하는 웹사이트입니다. 서버나 빌드 과정 없이 `index.html`을 브라우저에서 열면 바로 동작합니다.

## 실행

```bash
cd toeic
python3 -m http.server 8000
# http://localhost:8000 접속 (또는 index.html을 더블클릭)
```

GitHub Pages 등 정적 호스팅에 폴더째 올려도 됩니다.

## 과정

상단의 TOEIC / SQLD / ADsP / 컴활 2급 버튼으로 과정을 바꿉니다. 학습 기록, 연속 학습일, 일일 목표, 백업 파일은 과정마다 따로 저장됩니다.

| 과정 | 분량 | 구성 | 커리큘럼 |
| --- | --- | --- | --- |
| TOEIC | 단어 1,467개 | 12개 주제 (인사·채용, 재무·회계, 계약·법률, 900+ 고급 어휘, Part 5 빈출 등) | 30일, 하루 50단어, 기초에서 고급 순 |
| SQLD | 용어 201개 | 데이터 모델링의 이해, 데이터 모델과 SQL, SQL 기본, SQL 활용, 관리 구문 | 14일, 하루 15용어, 과목 순 |
| ADsP | 용어 236개 | 데이터 이해, 데이터 분석 기획, R 기초와 데이터 마트, 통계 분석, 정형 데이터 마이닝 | 16일, 하루 15용어, 과목 순 |

- TOEIC 단어: 품사 · 뜻 · 동의어 · 예문 · 난이도(기초 700 / 중급 800 / 고급 900+)
- SQLD·ADsP·컴활 2급 용어: 분류 · 정의 · 핵심 키워드 · 시험 포인트 문장 · 난이도(기본 / 핵심 / 심화)
- SQLD는 2024년 개정 출제 범위(데이터 모델과 SQL, 정규 표현식, PIVOT 등 포함)를 기준으로 작성했습니다. 시험 범위와 문항 구성은 한국데이터산업진흥원 공지를 함께 확인하세요.
- 컴활 2급은 필기 두 과목을 Windows 10과 엑셀 2021 기준으로 작성했습니다. 함수와 바로 가기 키도 용어로 들어 있어 직접 입력 퀴즈로 철자를 연습할 수 있습니다. 시험 범위와 프로그램 버전은 대한상공회의소 공지를 함께 확인하세요.

## 기능

- **플래시카드 + 간격 반복(SRS)**: 아는/모르는 응답에 따라 1·3·7·14·30·60일 간격으로 복습 예약, 틀린 카드는 세션 안에서 즉시 재출제
- **퀴즈**
  - TOEIC: 영→한, 한→영, 동의어(Part 7 대비), 빈칸 채우기(Part 5 대비), 스펠링 입력, 혼합
  - SQLD·ADsP·컴활 2급: 용어→설명, 설명→용어, 빈칸 채우기, 직접 입력, 혼합. 오답 보기는 같은 분류의 용어에서 먼저 뽑아 헷갈리는 개념끼리 비교하게 됩니다
  - 범위(전체·레벨·영역·Day·취약 항목)와 문항 수 선택 가능
- **단어장 / 용어집**: 검색, 영역·레벨·학습 상태 필터, 즐겨찾기, TOEIC은 발음 듣기(브라우저 TTS)
- **통계**: 준비도 지표, 학습 단계 분포, 6주 학습 히트맵, 복습 예정표, 퀴즈 기록, JSON 백업·복원
- 키보드 단축키: 플래시카드 `Space` 뒤집기 · `1` 몰라요 · `2` 알아요, 퀴즈 `1~4` 선택 · `Enter` 다음
- 다크 모드, 모바일 대응

## 파일 구조

```
toeic/
  index.html        # 진입점, 아이콘 스프라이트
  style.css         # 스타일 (라이트/다크 테마)
  app.js            # 과정 정의, 라우팅, SRS, 플래시카드, 퀴즈, 단어장, 통계
  data/words_*.js   # TOEIC 카테고리별 단어
  data/sqld.js      # SQLD 용어
  data/adsp.js      # ADsP 용어
  data/comp2_1.js   # 컴활 2급 1과목 컴퓨터 일반
  data/comp2_2.js   # 컴활 2급 2과목 스프레드시트 일반
```

### 항목 추가·수정

데이터 파일의 배열에 한 줄을 추가하면 됩니다.

```js
// TOEIC
["단어", "품사", "뜻", "동의어", "예문", 레벨(1|2|3)],
// SQLD · ADsP · 컴활 2급: 시험 포인트 문장에는 용어가 그대로 들어가야 빈칸 퀴즈에 쓰입니다
["용어", "분류", "정의", "핵심 키워드", "시험 포인트 문장", 레벨(1|2|3)],
```

새 과정을 추가하려면 데이터 파일을 만들고 `app.js`의 `COURSES`에 항목을 하나 더하면 됩니다.
